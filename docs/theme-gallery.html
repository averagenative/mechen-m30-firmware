MECHEN M30 menu themes

Design exploration for the player's 320x240 TFT. Every mockup is drawn at the real pixel size, so what you see at 1x is what the screen would show. Nothing here touches the firmware build.

How this maps onto the firmware

  • Screen. 320x240, RGB565, no alpha channel. All UI art is stored as raw uncompressed bitmaps inside the .sty resource files in FWIMAGE.FW.
  • Main menu. mainmenu.sty holds six full 320x211 frames, one per selected item, plus a 320x29 top bar. The frames contain the icons and the dial; the firmware only draws the item name. So any layout here is a pure bitmap swap as long as the frame stays 320x211. The file is 1.85 MB and the per-entry sizes are fixed, so new art must match each slot's dimensions exactly.
  • Labels. Layouts that show all six names at once (grid, split, tiles, type, wheel, retro) bake the names into the frames. The firmware will still draw its own label in the top bar. That is harmless for most of them, but to hide it you would need a small code patch to find the label call in mainmenu.ap.
  • Lists. common.sty has the 320x240 list background, a solid 310x29 selection bar, seven more 310x29 bars, status-bar icons, digits, and the 320x240 volume popup. Changing the accent of every list means repainting the selection bar and the bars; the text colors are set in code.
  • Now playing. music.sty has the 150x150 art placeholder, transport buttons, a 231x6 progress track and fill, and small info icons. Also bitmap swaps.
  • Light themes. Paper works for bitmaps, but text drawn by the firmware is white, so a light theme needs the text color changed in code too. Treat it as the most expensive option.
  • Lead. The string tables ship a Theme setting with Blue, Gray, Green, Pink and Red names (THEME_RED and friends in setting.sty), but only the red art is present and nothing in setting.mcg mentions it. It looks like an SDK feature MECHEN left out. If the code path survived, the accent recolor might be a toggle rather than new art. Worth a look before repainting anything.
  • Leftover. mainmenu.sty also carries an unused orange 320x176 frame with a different five-item dial. That is the Amber theme's starting point.
